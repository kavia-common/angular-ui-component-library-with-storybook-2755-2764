# Storybook for Angular Component Library

Scripts:
- npm run storybook — start Storybook at http://localhost:6006
- npm run build-storybook — build static Storybook

Theme:
- Ocean Professional (primary #2563EB, secondary #F59E0B, error #EF4444, background #f9fafb, surface #ffffff, text #111827)

Notes:
- The global preview applies CSS variables and minimal classes (.ocean-card, .ocean-button) to reflect the theme in stories.
- Replace the AppComponent story as real reusable components are added to the library.
